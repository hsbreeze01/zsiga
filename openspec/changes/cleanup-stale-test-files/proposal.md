# cleanup-stale-test-files

## Summary
Remove stale test_spec_* files from tests/ that belong to archived or deleted proposals.

## Problem
The tests/ directory has 74 files, many are test_spec_* generated by VERIFY phase of proposals that have since been archived or deleted:
- test_spec_sre_subagent_design__* (7 files) - proposal deleted
- test_spec_auto_metric_degradation_* (4 files) - proposal deleted
- test_spec_push_local_commits_to_remote__* - proposal deleted
- test_spec_enable_sub_agent_gates__* - proposal deleted
- test_spec_fix_learnings_noise_and_inject__* (4 files) - old proposal
- test_spec_add_health_check_endpoint__* - archived
- test_spec_add_proposal_stats_to_dashboard__* - archived
- test_spec_add_uptime_to_status_api__* - archived
- test_spec_dashboard_add_feedback_loop_metrics__* - archived

These pollute every new proposals VERIFY phase which runs ALL tests including stale ones.

## Technical Design
Delete stale test_spec_* files from tests/. Keep conftest_zsiga.py and all non-spec test files.

Files to delete: all test_spec_* files (their proposals are archived or deleted).

## Acceptance Criteria
1. tests/ contains no test_spec_* files
2. conftest_zsiga.py and non-spec tests remain
3. pytest tests/ -x passes for remaining tests

## Scope
- In scope: Delete stale test files in tests/
- Out of scope: Source code changes

## Risk
- Impact: Very low - deleting tests for non-existent proposals
- Reversibility: Files in git history
