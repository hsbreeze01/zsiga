## 建议

1. **先做分析，再写 proposal** — 如果你想改进 `config.py`，应该先跑一轮 scout/analyst，找出具体问题（比如"函数 X 缺少错误处理"、"逻辑 Y 存在重复代码"），然后基于具体发现写 proposal。先有问题，再有方案。

2. **重写 BAC 使其可自动验证** — 示例：
   - `[BAC-01] tests/test_config.py 中存在 test_validate_config_invalid_input 且通过 pytest`
   - `[BAC-02] zsiga/config.py 中 load_config 函数体 <= 30 行`
   - `[BAC-03] pytest tests/test_config.py 返回 exit code 0`

3. **明确单一改进目标** — 不要"探索并改进"。选一个具体目标：比如"为 `validate_config` 添加错误路径测试覆盖"，或者"提取 `_resolve_env_vars` 中的重复逻辑为辅助函数"。
